# Flow UI Cleanup / Arayüz sadeleştirme

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/flow-ui-cleanup/).

Dekoratif panodan okunabilir bir ölçüm ekranına geçişi izle.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Gösterge adı
- Debi (L/s)
- Kart sayısı

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Preview a simplified dashboard with your own label, reading and tile count.

Open [the live tool](https://omerbek.github.io/flow-ui-cleanup/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
